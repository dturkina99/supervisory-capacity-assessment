The document
The record file (.json)

The record file is a plain-text .json file saved to your own computer, holding every field, the registered snapshot and its check code. Open it here to continue later. Keep it with the PDF: it is the machine-readable copy, and anyone can recompute the check code from it. Move it out of your Downloads folder into the engagement's own folder; it contains everything on the page. Nothing is kept in the browser.
