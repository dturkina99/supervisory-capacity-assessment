# Deposited data

The coding underlying the paper is deposited separately and is not duplicated here.

**Deposit:** [doi.org/10.5281/zenodo.22075225](https://doi.org/10.5281/zenodo.22075225) — CC BY 4.0

Contents:

- `framework_coding_sheet.csv` — every coded provision, with source section, excerpt, code and rationale; positive criteria and near-misses distinguished
- `negative_findings_log.csv` — term searches across the corpus, every hit resolved by section
- `text_layer_manifest.csv` — source documents with URL, extraction command, page and word counts, and SHA-256 of the text layer

The manifest records hashes rather than redistributing the source documents, which remain the copyright of their publishers. Short excerpts appear in the coding sheet only as far as needed to show what a coding decision rests on, each with its section reference. A reader who converts the same document with the same command can confirm their text layer is identical to the one the counts were computed on.

The coding was performed by one researcher. That is disclosed as a limitation in the paper. The sheet is published so that any individual coding decision can be disputed against the stated frame.
